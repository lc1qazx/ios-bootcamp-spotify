# Music Player

iOS Bootcamp Project 1. A SwiftUI music player screen inspired by Spotify, showing "The 1975" by The 1975. You can try the play/pause button, favorite button, and progress slider.

Open `SpotifyPlayer.xcodeproj` in Xcode and run it on an iPhone simulator.

Still a draft. This is a screen mockup and doesn't play music.
